# lab

A research lens on building — one of Sankha Cooray's research lenses.

Deployed at **[lab.sankhacooray.com](https://lab.sankhacooray.com)** via GitHub Pages.

## Members

This lens groups the following projects (see `lab-sankhacooray-com.code-workspace`):

- **skilldex** — A browser for Claude skills — static front over a small /api node backend.
- **scratch-gpt** — Natural-language to Scratch — an HTML front with an Apps Script bridge.
- **tab-export** — A Chrome MV3 extension for exporting and organising open tabs.
- **shopscout** — A shopping copilot — compare, track, and reason about purchases.
- **concur-copilot** — An MV3 assistant that streamlines expense workflows in Concur.
- **passkey** — A WebAuthn playground — a client front and a real relying-party server.
- **ytvault** — A private, personal collection layer over YouTube.
